# SoSyM case study and TLC scaling campaign

Artifacts for *Observation-Relative Consistency for Multi-View Models Built by Untrusted
Generative Agents* (`docs/paper/SoSyM/main.tex`). Every number in the article's
case-study and scaling sections is generated by `summarize.py` into the blocks of
`main.tex` marked `%% BEGIN GENERATED ...`; do not edit those blocks by hand.

## Files

| File | Content |
|---|---|
| `kernel.py` | Controller kernel: jobs, records, requests, reconciliation, the five coordination disciplines (`STRATEGIES`). Extends the differentially tested `src/vgc/graph.py` with projections, context selectors and owners. |
| `mde_case.py` | The 13-view library model: requirements, the seven changes E1–E7, the feedback epoch, validators, the global constraint `G`, the oracle, simulated agents and the prompt renderer. `make_jobs` is the workflow model (Fig. 4 of the article). |
| `run_case.py` | Discrete-event driver and monitor; campaigns `sim`, `impact`, `sweep`, `llm`. |
| `summarize.py` | Aggregates raw runs into `results/processed/sosym/summary.json` and the generated blocks of `main.tex`. |
| `../../scripts/run_models_sosym.py` | TLC scaling campaign (writes `models/sosym/*.cfg`, `models/Model_s_*.tla`, `results/processed/sosym/tlc-scaling*.json`). |

## Reproducing the article

Python 3.12 with `scipy` (for the Wilcoxon test). Times are for one workstation core.

```bash
python experiments/sosym/run_case.py sim    --runs 500   # RQ1, RQ3      (~25 s)
python experiments/sosym/run_case.py impact --runs 200   # RQ2           (~13 s)
python experiments/sosym/run_case.py sweep  --runs 100   # sensitivity   (~21 s)
python experiments/sosym/summarize.py                    # tables, macros -> main.tex
cd docs/paper/SoSyM && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Defaults: budget `k=4`, `p_mid=0.6`, `p_err=0.25`, mean latency 1, duplicate
probability 0.1, loss probability 0.05 (timeout 5). Seeds: run `i` uses schedule seed
`i` and agent seed `10000+i` (`sim`); `50000+i` / `20000+i` (`impact`);
`40000+i` / `30000+i` (`sweep`); `1000+rep` (`llm`). Every raw file carries a manifest
with arguments, git commit and SHA-256 of the sources. Use `--out DIR` to write raw
results somewhere other than `results/raw/sosym`.

### LLM campaign (RQ4)

Raw runs and every model call (prompt, reply, tokens, latency) are in
`results/raw/sosym/llm/<model>/{runs.json,cache.jsonl}`. The campaign can be replayed
from the cached calls **without a model server**:

```bash
python experiments/sosym/run_case.py llm --model gpt-oss:20b --reps 10 \
       --cache-only --cache-from results/raw/sosym --out /tmp/replay
```

A cache miss is answered with an empty (invalid) reply and counted in `cache_misses`;
`results/raw/sosym/llm-replay/` holds a replay of all eight models with the current
code, with zero misses and run-for-run identical results.

To query models again, serve them with Ollama and drop `--cache-only`
(`--host http://HOST:11434`). Settings: JSON mode, temperature 0.7, `num_predict`
1500, `num_ctx` 8192, seed derived from the cache key, HTTP timeout 900 s with three
retries. Answers are cached by model, prompt, attempt and repetition (not by
discipline), so all disciplines asking the same question receive the same answer.
`hpc/slurm/vgc_llm.sbatch` runs one model on a GPU node.

Models: gemma2:9b, gpt-oss:20b, llama3.1:8b, mistral-small:24b, phi4:14b,
qwen2.5-coder:7b, qwen2.5:7b, qwen3-coder:30b; deepseek-coder-v2:16b was excluded
(no completed repetition). Model weights are subject to their own licenses.

### TLC scaling campaign

Requires Java 17 and `tla2tools.jar` in `.tools/` (its SHA-256 is recorded in the output).

```bash
python scripts/run_models_sosym.py --workers 16 --heap 90           # all instances
python scripts/run_models_sosym.py --only base-s_mde5-k2-m2 --workers 62 \
       --out results/processed/sosym/tlc-scaling-base-s_mde5-k2-m2.json  # one instance
```

The three largest instances (`chain4`, `diamond4`, `mde5` with `k=m=2`) ran on a
cluster CPU node through `hpc/slurm/vgc_tlc.sbatch`; `mde5 k2 m2` took about 3.5 h with
62 workers. `summarize.py` merges the per-instance files.
