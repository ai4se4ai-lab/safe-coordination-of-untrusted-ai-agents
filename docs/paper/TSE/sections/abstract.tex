\begin{abstract}
Multi-agent frameworks built on large language models (LLMs) divide software development among agents that write designs, code and tests. Every individual answer can look valid while the workflow as a whole goes wrong. A slow agent answers a question that has since changed, two locally valid outputs disagree on an interface, or a reviewer added late is silently skipped. These are coordination problems. Multi-agent systems research addresses them by mediating interaction through shared artifacts and governors, and database and build-system research by optimistic commits and dependency tracking. We adapt these mechanisms to agents whose contributions are \emph{generated}: costly, nondeterministic, and valid only relative to what the agent was shown. A deterministic controller owns structure, dependencies, acceptance and publication, and agents only propose values for slots it creates. Each slot carries an exact dependency key over everything that shapes its question: inputs, selected context, instruction and validator. A commit guard admits a proposal only if it still answers the current question. We prove that no stale or unauthorized value becomes usable, that, under an upstream gate, a change triggers exactly one repair episode per affected slot, that every episode ends in a terminal outcome, and that asynchronous execution refines atomic execution. The refinement and the safety invariant are model-checked on bounded instances; the remaining results are proved on paper. Adversarial testing confirms that removing any non-redundant guard breaks its property. Exact keys cut generation requests by \RatioFull$\times$ on independent and \CoupledRatioFullFmax$\times$ on coupled workspaces. With \LlmModelsN{} open LLMs, the guard rejected every reply delivered after a controlled requirement change; \LlmStaleWrongPct\% of those that passed their original validator were wrong for the new requirement. On HumanEval+ and MBPP+, \BenchAcceptedWrongPct\% of values accepted by the base tests failed the stronger plus tests. Coordination guarantees hold for any agent, but correctness never exceeds the declared validators.
\end{abstract}
